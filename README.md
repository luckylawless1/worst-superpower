Entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on [make.fun](https://make.fun).

## The entry

> I can summon rain, but only inside my own shoes.

A superpower so useless that naming it is the whole joke: the rain arrives
exactly where it helps no one — not even the hero.

## How it works

`main.ts` (Node, stdlib only) writes the one-line entry to
`/output/entry.txt`. The line is 48 characters, a single line, within the
140-character gate. The program self-checks the gate (1–140 characters,
single non-blank line) and fails loudly instead of shipping an invalid entry.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
